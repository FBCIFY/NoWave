# Icône NoWave

`nowave-icon-original.png` est la capture fournie par l’utilisateur le 27 septembre 2026, conservée sans modification.

`nowave-icon.svg` est une transcription vectorielle du symbole fourni : courbes de Bézier, fond transparent et dégradés bleus. Aucun bitmap ni filtre de détourage : les contours restent nets à toutes les tailles. La capture originale reste la référence de marque.

`nowave-app-icon-original.png` est la seconde image fournie par l’utilisateur : la vague sur un carré bleu arrondi. Le favicon reprend exactement cette image, avec une fenêtre SVG de 992 × 992 et un chemin de découpe arrondi qui exclut le blanc extérieur. `../favicon.svg` et ses exports PNG de 32, 64 et 180 pixels partagent cette source. Aucun visuel généré n’est utilisé pour la marque.
