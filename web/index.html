NoWave est un projet d’application mobile pour explorer une carte maritime, signaler les obstacles, les animaux marins et les pollutions observés, avec une position, une heure et un commentaire.

Application en développement

Cet archipel est notre terrain de jeu. Les situations sont illustratives : elles expliquent les risques et le fonctionnement des signalements. Il ne s’agit pas d’une carte de navigation.

LES COULISSES DU LARGE

Un océan de clins d’œil.

Un monde original où chaque clin d’œil sert la mission de NoWave : observer, comprendre et signaler. Le Nautilus parle des dangers immergés ; le canard, des déchets ; le kraken, des gestes d’un signalement utile.

L’envie de se perdre dans une scène pleine de détails rend hommage à Floor796 ↗. Les visuels de cet archipel ont été créés pour NoWave par génération d’images.

Les illustrations, les coordonnées et les récits de cette expérience sont imaginaires. Aucun suivi publicitaire ni stockage de votre parcours.
