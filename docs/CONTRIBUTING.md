# Contribution

1. Créer une branche de travail depuis `dev` à jour.
2. Faire des commits ciblés et lancer les [tests concernés](TESTING.md).
3. Ouvrir une PR vers `dev`, avec le changement et les résultats des tests.
4. Obtenir la revue d’un autre membre et résoudre les remarques bloquantes avant fusion.
5. Après recette, promouvoir la release par PR de `dev` vers `main`.

Pas de développement ni de push direct sur `dev` ou `main`. Les secrets restent hors Git.
