# NW-195 — Erreurs de tuiles pendant l'installation

Vérification le 20 octobre 2026 sur la base `8fdb36c`.
Reproduction automatisée : bloquer l'installation, injecter une erreur 503,
attendre plus que la fenêtre de reprise de deux secondes, terminer
l'installation. Le contrôleur déclarait à tort la couche disponible.

L'échec est désormais mémorisé indépendamment du minuteur. La couche reste
indisponible jusqu'au chargement réussi d'une tuile et à la période sans
erreur. Le chargement d'un nouveau style efface l'état du style précédent ;
les 429 restent ignorées.

Validation : `flutter test --no-pub test/features/map/data/report_layer_controller_test.dart`.
Le nouveau scénario échoue avant correction. Couverture complémentaire :
reprise, nouveau style, limitation de débit, token et arrière-plan.
