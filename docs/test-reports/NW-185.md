# NW-185 — Contraste des contrôles cyan

Vérification le 20 octobre 2026 sur la base `8fdb36c`.
Les catégories sélectionnées utilisaient du blanc sur cyan ; le bouton
principal héritait également de sa couleur de texte.

Les deux contrôles emploient maintenant explicitement le texte bleu foncé
du formulaire, en conservant le fond cyan.

Validation : `flutter test --no-pub test/features/reports/presentation/report_composer_sheet_test.dart`.
Un test calcule le contraste des couleurs réellement portées par la catégorie
sélectionnée et le bouton actif et exige un rapport d'au moins 4,5.
