# NW-188 — Position publiée et conversion cartographique

Vérification le 20 octobre 2026 sur la base `8fdb36c`.
La publication lisait directement le dernier point mémorisé, même si une
conversion du marqueur vers les coordonnées était en attente.

La publication demande maintenant une conversion actuelle et attend sa réponse
(cinq secondes au maximum). Une réponse ancienne, une carte déplacée pendant
la conversion, un autre parcours ou des coordonnées invalides empêchent l'envoi.
Le formulaire conserve la saisie et propose de réessayer après stabilisation.
Les réessais HTTP gardent la logique d'idempotence existante.

Validation : `flutter test --no-pub test/features/map/presentation/map_focus_test.dart test/features/reports/presentation/report_composer_sheet_test.dart`.
Les suites passent : 29 tests carte et 8 tests formulaire. Les nouveaux scénarios
couvrent une réponse lente, le mouvement pendant la conversion et une erreur
suivie d'un réessai réussi. Les appels natifs et l'API sont simulés.
