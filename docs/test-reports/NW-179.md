# NW-179 — Position courante dans la fiche d'une alerte

Vérification le 20 octobre 2026 sur la base `8fdb36c`.
`AlertReportScreen` ne transmettait jamais de position à `ReportDetailSheet`.
La distance restait donc inconnue, même avec un GPS disponible.

La fiche récupère une position à son ouverture si l'autorisation existe déjà.
Elle transmet les coordonnées au détail dès leur arrivée, sans bloquer le
chargement du signalement ni réutiliser la position historique du push.
Un refus ou un échec GPS conserve la fiche consultable sans distance.

Validation : `flutter test --no-pub test/features/alerts/presentation/alert_report_screen_test.dart`.
Cas ajoutés : GPS tardif, permission refusée, échec GPS. Les scénarios
d'expiration, de relecture et de navigation sont conservés.
La localisation est simulée ; pas de recette capteur native.
