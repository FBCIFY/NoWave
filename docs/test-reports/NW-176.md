# NW-176 — Avertissement persistant de couche indisponible

Vérification le 20 octobre 2026 sur la base `8fdb36c`.
Un appui sur le bandeau masquait toute indication d'indisponibilité jusqu'au
prochain changement d'état, même si la panne persistait.

Fermer le message détaillé conserve désormais « Signalements indisponibles ».
Le détail revient à chaque changement d'état et l'avertissement disparaît
quand la couche est rétablie.

Validation : `flutter test --no-pub test/features/map/presentation/map_focus_test.dart`.
Le test simule une installation en échec et deux appuis successifs ; l'état
reste visible. Les interactions cartographiques utilisent un double Mapbox.
