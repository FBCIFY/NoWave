# NW-177 — Intervalle entre les envois GPS

Vérification le 20 octobre 2026 sur la base `8fdb36c`.
Le minuteur démarrait avec le suivi, alors que la première mesure pouvait
arriver plus tard : une première mesure à 59 secondes puis le tick à 60
secondes permettaient deux envois espacés d'une seule seconde.

Un temps monotone mesure désormais l'intervalle depuis la dernière tentative.
Une nouvelle mesure ou un réessai réseau attend au moins 60 secondes, sans
perdre la mesure en attente. Le premier envoi après démarrage reste immédiat
et l'arrêt réinitialise le suivi. La récupération d'un téléphone non enregistré
(404, enregistrement puis renvoi de la même mesure) reste dans le même envoi.

Validation : `flutter test --no-pub test/core/device/device_position_reporter_test.dart`.
28 tests passent : première mesure tardive, seuil à 60 secondes, échec réseau,
filtre de distance, précision, arrière-plan, arrêt et déconnexion.
Les tests utilisent une horloge monotone simulée, sans suivi GPS natif.
