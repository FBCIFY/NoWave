# NW-193 — Fin du flux GPS natif

Vérification le 20 octobre 2026 sur la base `8fdb36c`.
Le relais broadcast restait ouvert après la fin de sa source native. La carte,
la caméra et le reporter n'étaient pas avertis et aucun réabonnement ne partait.

La fin native produit désormais une erreur explicite et programme une reprise
après 15 secondes, avec les réglages de suivi en vigueur. Le départ du dernier
abonné annule cette reprise. Une génération empêche les anciens abonnements
de publier des événements après un changement de mode ou un arrêt.

Validation : `flutter test --no-pub test/core/location/location_service_test.dart`.
5 tests passent, dont fin native, livraison aux abonnés après reprise,
conservation du mode arrière-plan et annulation après le dernier départ.
Le délai est réellement attendu dans ces deux tests pour respecter le relais
statique partagé entre les tests. Le flux natif est un double Geolocator ;
la recette des restrictions Android/iOS reste à effectuer sur téléphone.
