## Matrice automatisée exécutée

Chaque case traverse AlertPushController, HomeScreen, le vrai
ReportDetailService/ApiService et le parseur de réponse HTTP avec MockClient,
puis le fake Mapbox. Elle contrôle la même instance de carte, l'ID, la position
et la catégorie API (payload FCM volontairement pollution), le badge, l'absence
de fiche/téléchargement automatique, les doublons et notifications successives,
puis le tap volontaire sur le repère du bon rapport. La photo disponible est
chargée seulement après le tap. Aucune connexion Firebase ni MVT réelle.
