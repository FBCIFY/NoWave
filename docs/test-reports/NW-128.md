### A01 — Fixture AuthGate non préparée au stockage NW-126 — moyenne, test uniquement, corrigée

Environnement : baseline `ce7a607`, E-A/B-M. Précondition : lancer les trois tests `features/alerts/presentation/auth_gate_alerts_test.dart` après merge.
