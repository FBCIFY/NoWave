# NW-180 — Information sur le suivi GPS

Vérification le 20 octobre 2026 sur la base `8fdb36c`.
Le profil proposait « Alertes à proximité » sans expliquer que cette préférence
active également le suivi GPS en arrière-plan dans `DevicePositionTracker`.

Une explication permanente accompagne désormais l'interrupteur : finalité,
autorisations du téléphone, impact possible sur la batterie et arrêt du suivi
en arrière-plan à la désactivation. Le comportement des permissions et du
suivi n'est pas modifié.

Validation : `flutter test --no-pub test/features/profile/presentation/profile_screen_test.dart`.
Ces tests couvrent notamment le petit écran défilable, les préférences et
les permissions simulées ; aucun essai GPS natif n'est revendiqué.
