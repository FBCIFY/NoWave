# Icônes de bouées

Douze PNG NoWave transparents de 72 × 72 px. Ratio Mapbox : 3 pour les symboles
qualifiés, 18 pour le symbole neutre. La classification suit les règles IALA A/B.

Le SVG historique vient de [Temaki](https://github.com/rapideditor/temaki), sous
[CC0](LICENSE-Temaki.md). `mobile/tool/make_buoy_icons.py` régénère les anciens
dessins ; les PNG actuels sont des assets fournis séparément.
