# Captures de revue graphique

Six scénarios fictifs, observés dans le POC Flutter avec son chargement MapLibre CDN.
DEM réel externe Mapzen/AWS ; toutes les profondeurs et données nautiques restent fictives.

La comparaison scénario par scénario, les positions, tests et limitations figurent dans
[VISUAL_REVIEW.md](../../VISUAL_REVIEW.md). `browser-result.json` contient les réponses DEM,
les erreurs, les couches rendues, les zooms contrôlés et les vérifications pan/zoom.
`before/demo.png` est un état historique avec un autre cadrage, pas un avant/après pixel à pixel.
